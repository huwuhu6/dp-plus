## B. Evaluator 审计

1. **P1 EVALUATOR_FALSE_NEGATIVE（已在 Run 167 前修正）**：optional V2 field 被 projection 省略时 `{null:true}` 原先失败；不计作生产能力提升。
2. **P0 EVALUATOR_FALSE_POSITIVE**：`hardConstraintsVerified = verificationFailures.isEmpty()`（`AiConversationEvaluationService:1475`）。verifier 未执行、runtime catch 或无 candidates 也会被记录为 true；不能作为 hard constraint pass。
3. **P1 EVALUATOR_FALSE_POSITIVE**：`matchesExpectedCity` 在 expectedCity 非空且 final ids 为空时直接 true（`:1184`）。
4. **P1 OBSERVABILITY_GAP**：`compileExecuteVerify` catch RuntimeException 后生成 FAILURE observation，但 evaluation 的 `actualErrorCount` 不保证获知内部异常（`V2ChatOrchestrator:163-174`）。
5. **P1 metric flaw**：Run duration 是整个 multi-turn case trajectory，不是单轮用户 latency；应命名 CASE_TRAJECTORY_LATENCY。模型 calls/turn、repair rate 与 repair latency 当前没有 run aggregation。
6. Case Pass 只包含 locality/final status/shop/recovery/unseen/v2Outcome/unexpected error（`:966`）；memory/tool/tool arguments/turn states/relations 多为 diagnostics，当前 Main 的核心 V2 invariant主要在 v2Outcome，未见只写在 diagnostic 的核心约束。
7. V2 Outcome matchedCount 粒度为 **case**：`finish()` 统计 `result.getV2OutcomeMatched()`，而该值仅在该 case 的全部 expected V2 outcomes 都匹配时为 true。它必须与 Case Pass 分开报告；turn expectation 与 assertion-field accuracy 尚未聚合。
